## Problem Statement
Nigerian molecular labs face 2-6 month delays for reagents (Taq, enzymes) while same reagents expire unused in neighboring labs. No sharing system exists. Simultaneously, erratic power destroys -20/-80°C cold-chain samples without alerts.

## Value Proposition
1. Accelerate: Months → 48hrs via peer sharing
2. Prevent Loss: Live freezer monitor + WhatsApp/SMS alerts
3. Convert Waste to Value: Freezer failure auto-flags reagents as AT RISK emergency swap for nearby rescue.
